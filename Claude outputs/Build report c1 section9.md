## 4. Known gaps and the authoring TODO

1. **Reading sits at ~2% against a 5% target in both sections.** This is honest
   rather than fixable by generating more items: at A1 there is very little text
   long enough to read. The fix is graded readers in the Immersion Engine
   (docs/06 §7), not more exercises.
2. **Grammar items are ~4 points below target.** Each grammar point now has
   exactly one home node, which is correct; the shortfall should be closed with
   hand-authored contrast items rather than more generated variants.
3. **Item volume runs at roughly 60-70% of the modelled lesson time.** Each
   node-tier averages ~13 items where ~16-18 are needed. The remainder should be
   hand-authored variety, not more of the same templates.
4. **All audio is referenced but not recorded.** Human voices are required below
   C1 (docs/15 §5).
5. **No images yet.** `mcq_image` and `listen_choose_image` are unused for that
   reason; at A1 they matter, and image sourcing is the next media task.
6. **C1 is authored.** Section 9 added 48 grammar points (G-279…G-326), 12
   phonology points (P-079…P-090), 24 functions (F-131…F-154), 421 lexemes, 24
   story episodes and 72 comprehension questions. It is the largest section so far
   and the first that is grammar-led rather than vocabulary-led.
7. **C1 has less new vocabulary than B2.1 — and that is the finding, not a gap.**
   Of 409 candidate words probed as "C1", **195 were already taught**. B2 had
   consumed far more of the educated lexicon than expected. Three probes produced
   a raw pool of 585; cutting the layer that lives inside one discipline's own
   literature (`explanandum`, `heteroglossia`, `allomorph`, `apodictic`) left
   **421** — about 18 per unit, against B2.1's 50 and B2.2's 36. So Section 9
   carries its weight in 48 grammar points and in discourse rather than in new
   words, which is what C1 actually is: not more vocabulary, but better judgement
   about the vocabulary you have. This is the fourth section whose honest target
   came out different from the flat number in docs/13 §3.1, and the fourth time
   measuring first was right.
8. **The first lexeme assignment was written from memory and had to be thrown
   away.** 274 of 311 words in it had never been in the verified pool. This is
   exactly the failure the README warns about, made by the person who wrote the
   warning. The rebuilt assignment is drawn from the pool file itself and checked
   against it: 421 assigned, 0 invented, 0 duplicated, 0 left over.
9. **A fourth wave of missing everyday words — 55 of them, and one shape is new.**
   The three shapes Section 8 named all recurred. *One part of speech only*:
   `dispute`, `draft`, `respect`, `flood`, `surface` and `direct` existed as nouns
   or adjectives and never as verbs. *A derived form assumed*: `careless` without
   `carelessness`, `accuse` without `accusation`, `sure` without `unsure`, `write`
   without `rewrite`. *Never taught at all*: `above`, `inside`, `dead`, `alive`,
   `care`, `fill`, `spread`, `stone` — A1 words, and `above` and `inside` are
   prepositions a beginner needs in the second week. The new shape: the course
   teaches `noun`, `verb`, `adjective` and `adverb` (added in Section 8) but had
   never taught **`passive`**, the one piece of metalanguage its own B2 grammar
   leans on hardest. Running total across Sections 6-9: **169 everyday words** the
   course had never taught.
10. **Eight C1 IPA transcriptions were wrong, and again no gate could see it.**
   `naivety` had /nɑ-/ for /naɪ-/, `acumen` had first-syllable stress, `renaissance`
   had the British pattern, `prescient` was a syllable short. Ten were wrong in
   Section 8. This is now a standing item: read every transcription before shipping
   a section, because the schema will accept any string and the audio is built
   from it.
11. **Sixteen of the 72 questions were answerable without reading the episode.**
   Fifteen of 54 in Section 8; sixteen of 72 here. The failure mode is stable — the
   keyed answer ends up the longest option because it is the one being written
   carefully. The fix is equally stable: rewrite the distractors to full length,
   each still wrong for a reason a reader could name. Worth building a gate for,
   since it recurs at exactly the same rate.
12. **193 band-1000 lexemes are still first taught at B1 or later** — gate G24,
   unchanged since Section 6. Four sections have now cleared the words their own
   stories needed without touching the backlog. It should be done as one pass over
   Sections 1-4, not a fifth time in fragments.
13. **Section 10 (C2, units 145-168) is the last** — 24 units. The specialist layer
   cut at B2.2 and again at C1 is waiting for it, so unlike every section since B1
   its vocabulary pool is already identified and probably ample. The pipeline needs
   no changes.

## 5. How to rebuild

```
./build.sh
```

which runs, in order:

```
python3 tools/build_lexemes.py   # compact sources  -> build/lexemes.json
python3 tools/build_units.py     # unit specs       -> build/units/*.json
python3 tools/build_items.py     # everything above -> build/items/*.json
python3 tools/validate.py        # the CI gates (exit 1 blocks a merge)
python3 tools/report.py          # this file
```

Builds are deterministic (`random.seed(20260908)`), so the same sources always
produce the same item ids.
